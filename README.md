# 🎯 CTF Writeups

> Documentación de máquinas y desafíos resueltos en plataformas de CTF

## 📖 Descripción

Este repositorio contiene writeups detallados de máquinas y desafíos de **Capture The Flag (CTF)** que he resuelto. Cada writeup incluye:

- 🧩 Análisis del desafío/máquina
- 🔍 Metodología de resolución paso a paso
- 💡 Técnicas y vulnerabilidades explotadas
- 🛠️ Herramientas utilizadas
- 📝 Scripts y payloads relevantes
